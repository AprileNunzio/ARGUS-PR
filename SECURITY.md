# Security Policy / Politica di Sicurezza

[English Version](#english-version) | [Versione Italiana](#versione-italiana)

---

## English Version

Security and surveillance stream confidentiality are foundational to **ARGUS-PR** (*Nunzio Aprile / NunzioTech*). We appreciate responsible disclosure of potential security vulnerabilities.

### Supported Versions

We provide security patches for the following versions:

| Version | Supported |
|:---|:---:|
| 1.0.x | :white_check_mark: |
| < 1.0.0 | :x: |

### Reporting a Vulnerability

If you discover a security vulnerability in ARGUS-PR, please **DO NOT** open a public issue. Follow our coordinated vulnerability disclosure process:

1. **Private Disclosure**:
   Send an email to project leadership:
   - **Contact**: `info@nunziotech.com`
   - **Subject**: `[ARGUS-PR Security] Vulnerability Report - <Brief Summary>`

2. **Information to Include**:
   - Vulnerability category (e.g. Path Traversal, Auth Bypass, Denial of Service, Injection).
   - Affected subsystem (backend API, stream pipeline, web UI, native launcher).
   - Reproduction steps and proof of concept.
   - Potential impact assessment.

3. **Response & Remediation**:
   - We will acknowledge receipt within **48 hours**.
   - We will coordinate patch timeline and release prior to public disclosure.

## Versione Italiana

La sicurezza e l'integrità dei flussi di videosorveglianza e dei dati sensibili sono al centro della progettazione di **ARGUS-PR** (*Nunzio Aprile / NunzioTech*). Apprezziamo la cooperazione della comunità per la divulgazione coordinata e responsabile delle vulnerabilità.

### Versioni Supportate

Forniamo aggiornamenti di sicurezza e patch per le versioni indicate:

| Versione | Supportata |
|:---|:---:|
| 1.0.x | :white_check_mark: |
| < 1.0.0 | :x: |

### Segnalazione di una Vulnerabilità

Se hai individuato una vulnerabilità di sicurezza in ARGUS-PR, ti chiediamo di **NON** aprire una segnalazione pubblica:

1. **Invio della Segnalazione Riservata**:
   Invia una comunicazione dettagliata a:
   - **Contatto**: `info@nunziotech.com`
   - **Oggetto**: `[ARGUS-PR Security] Segnalazione Vulnerabilità - <Breve Descrizione>`

2. **Dettagli da Includere**:
   - Natura della vulnerabilità e impatto potenziale.
   - Componente interessato e passaggi dettagliati per la riproduzione (Proof of Concept).

3. **Gestione del Riscontro**:
   - Riceverai riscontro entro **48 ore** con piano di rilascio coordinato.
